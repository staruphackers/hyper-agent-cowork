# v2026.925.0-zhtw.6

**類型**：修正版（bugfix）　**基於**：v2026.925.0-zhtw.5　**建版目標 commit**：`22435f8`

## 摘要

修正「把代理人的轉接器從 Grok／Codex／Claude 切到 Pi 等」時，儲存或測試連線出現 `Select an AI connection compatible with this harness and model` 的問題，並補上 Pi 轉接器的設定提示。

## 變更

### 修正
- 切換轉接器時，若新轉接器不支援 AI 連線（Connections）綁定，舊的訂閱連線綁定會自動移除，不再帶到新轉接器上導致 422。（`22435f8`）

### 介面
- Pi 轉接器設定頁新增提示：Pi 只吃供應商 API key（OpenAI、Anthropic、OpenCode 等），Claude Code／Codex 的訂閱登入對 Pi 無效；要用 ChatGPT 或 Claude 訂閱請改用 Codex 或 Claude Code 轉接器。（`7031b59`、`edbe206`）

## 升級注意
- 沒有資料庫變更，直接換映像 tag 即可。

## 驗證
- 把一個 Grok 代理人切到 Pi、填 OpenCode API key、選 `opencode-go/<model>`，儲存與測試連線都應成功。
