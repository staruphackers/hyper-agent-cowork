# v2026.1026.0-zhtw.13

**類型**：上游同步版（大版）　**基於**：v2026.1019.0-zhtw.12　**建版目標**：`main`

## 摘要

這版把上游 Paperclip 從 9/24 到 10/25 的 1,110 個 commit 一次併入，並把 fork 自己的修正逐項搬到上游重構後的新位置。同時把後台繁中翻譯補齊並統一用語：新增詞彙表，`check.mjs` 會擋下大陸用語與機器翻譯腔。

**這版有 94 支資料庫遷移，升級前一定要備份，並先在 staging 走一遍驗收清單。**

## 上游帶進來的重點

- **穩定性**：heartbeat 在重啟、遺失 lease、留言中斷重試時的復原；wake queue 被停止的排隊 run 保留待辦；OpenCode 沙箱記憶體不足時保住代理人；Pi 執行紀錄不再無限長大。
- **Docker**：伺服器改從預編譯 bundle 啟動，開機不再整棵目錄 chown，重啟更快。
- **新功能**：Git 工作區還原點與過期回收、代理人批次改連線與預設模型、訂閱月費與 API 花費並列的成本頁、私人任務、自訂 AI gateway、Claude 瀏覽器登入（setup token）、Artifacts（實驗功能）。
- **安全**：雲端認證 header 遮罩、提示詞注入防護、遮罩規則改成整個欄位名稱比對（減少誤遮）。

## 行為改變（請留意）

- **新增代理人精靈改成「先建草稿、再連線、最後完成」**：一進精靈就會先建立一個暫停中的草稿代理人；中途離開可以從代理人列表繼續設定。
- **Claude、Codex、Pi、OpenCode 新代理人預設改用 Paperclip Runner**（上游行為）。舊代理人不受影響。若你的 VPS 映像跑不起來，在建立時把 Runner 改回 legacy。
- **Pi 與 Gemini CLI 可以使用受管 AI 連線**（上游新增）。
- **登入畫面**：裝置碼登入改用上游的卡片樣式，原本 zhtw.11 的「兩個編號步驟」改為上游版本；功能相同（顯示驗證碼、前往授權）。
- **遮罩規則**：機密欄位改成整個名稱比對。像 `authTimeoutMs`、`maxRawInputTokens` 這類數字設定不再顯示為 `***REDACTED***`。
- **建置**：上游映像會一起編譯 Rust 版 Paperclip Runner，GitHub Actions 建版時間會變長；Node 需求提高到 24.11 以上（Docker 映像已是 Node 24）。
- **CI**：`pr.yml` 改跑本 repo 自己的 `pr-trusted.yml`，不再呼叫上游 `@master`。

## 繁中翻譯

## 已知限制

- **新增代理人精靈的 OpenCode 方案標示**只在 Provider API key 模式下顯示分組與「免費」標記；OpenRouter 連線模式沿用上游的原生下拉選單。
- **「卡住任務」掃描**仍未處理孤兒等待中喚醒（zhtw.12 已知限制，未變）。
- **測試環境逾時**：本機容器較慢，少數測試第一次執行會超過預設 15 秒逾時；放寬逾時後全數通過，同一支測試在未改動的上游版本上也一樣逾時，與本版無關。
