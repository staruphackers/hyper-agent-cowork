# v2026.925.0-zhtw.8

**類型**：功能版（Phase 1 Runtime Profiles）　**基於**：v2026.925.0-zhtw.7　**建版目標**：`main`（`aefa9c2` 或之後的文件 commit）

## 摘要

一個代理人可以保存多組「執行設定」（轉接器＋模型＋AI 連線＋預設環境），在設定頁一鍵切換並先看到預檢摘要；每組設定各自保留任務對話 session，切回來可以續接。設計見 `doc/plans/2026-09-26-runtime-profiles-phase1.md`，操作見 `doc/zh-TW/VPS-DEPLOY.md` 第 6.2 節。

## 變更

### 功能
- 代理人「執行環境」分頁最上方新增「執行設定組」面板：把目前設定存成一組、啟用（含執行中 run 數、可續接 session 數的預檢與確認）、重新命名、刪除；每個代理人最多 8 組；分級 primary／economy／fallback／specialist 目前只是標籤。
- 啟用走與一般儲存相同的驗證路徑（模型清單、AI 連線相容、環境 driver、執行中 run 的 409 保護、設定修訂紀錄）。
- 在啟用中的設定下做的修改會自動存回該組設定。
- 新 API：`GET/POST /api/agents/:id/runtime-profiles`、`PATCH/DELETE /api/agents/:id/runtime-profiles/:profileId`、`POST …/:profileId/preflight`、`POST …/:profileId/activate`；活動紀錄 `agent.runtime_profile_created／updated／deleted／activated`。
- `runtimeConfig.aiConnection: null` 可明確清掉已存的連線綁定。
- 實例設定 → 實驗功能新增「Runtime Profiles」開關（self-hosted 預設開，只影響介面）。

## 驗證
1. 存一組 `primary`；再存一組 `economy` 並啟用，改成 OpenCode 便宜模型儲存。
2. 派一個任務跑完，切回 `primary`，預檢應顯示可續接的 session，舊對話續接。
3. 任務執行中切換 → 要求「取消 run 並啟用」。
4. 刪除未啟用的 `economy` → 成功；刪除啟用中的 → 被擋。
